Where the pixels went

A literal 4:3 card doesn't fit twice

At a 278px column width, the foundation Card/HeritageItem's 4:3 image is 208px tall on its own — before any title, type label, or chip. Two such cards, stacked with header, filter row, paging, and nav around them, need roughly 1,050px of vertical space in an 800px frame. There is no chrome trim that closes a gap that size, so the card itself had to change shape, not just its container.

Decisions & caveats

What to check before this ships

Filter chips grew from 44px to 64px

The foundation Chip/Category is a 44px status label — fine for a non-interactive tag on a card, but here it's the actual filter control. Your own touch rule sets a 64px floor for every interactive target, so a literal 44px chip would violate the system it's built from. I sized the filter chips to 64px and kept the rest of the pill styling; the base Chip/Category stays 44px wherever it's just labelling something.

The card's image shrank from 4:3 to roughly 2.7:1

This is the biggest liberty on the page. A true 4:3 thumbnail is unusable at this density — see the budget table. The alternative was fewer results per page, but you asked for 4×2 specifically, so I kept the count and changed the crop. A portrait-oriented scan will lose a lot of its frame at this ratio; worth a real check once photography is in.

Chips moved from stacked-below to overlaid-on-image

Stacking a full 44px Verified/AI chip under the title, on top of an already-compressed body, didn't fit at any reasonable size. Overlaying a smaller badge on the image corner reclaims that space entirely. The badge text still sits at 17px — the system's absolute type floor — so it shrank in footprint, never below the size an eye can actually read.

Right arrow also dims at the last page

Only the left arrow's page-one dimming was specified. I gave the right arrow the same treatment at page six for the same reason stated in the brief — an arrow that still looks tappable but silently does nothing is worse than one that visibly can't be pressed.

Trailing filter chips are a proof, not a taxonomy

"1920s–1950s" chips exist only so the horizontal scroll has something to scroll to. Real period sub-filters would presumably appear after "By period" is tapped, which is an interaction this prompt doesn't specify — flagging it as open for whichever prompt defines filter drawers.

Card art is a stand-in, same as prior screens

Drawn manuscript-page and portrait fragments, not scans — present to prove the overlay badges stay legible against both a busy page and a plain field. Swap for real photography and re-check the badge backdrop-blur still holds contrast.

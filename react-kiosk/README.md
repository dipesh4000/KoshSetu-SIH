# Ambedkar Digital Heritage — React Demo

This folder is the showcase-ready React conversion. The original static HTML
prototypes in the parent folders remain unchanged.

## Run locally

```powershell
npm install
npm run dev
```

## Recommended presentation path

1. Home → **Explore the archive**
2. Open **Annihilation of Caste**
3. Select **हिंदी अनुवाद** to show the hardcoded translation
4. Play the simulated narration and open a cited source
5. Visit **Ask the Archive** to show a prepared source-grounded answer

The archive outputs, translation, media progress and research answer are
demonstration content. No backend is required.
